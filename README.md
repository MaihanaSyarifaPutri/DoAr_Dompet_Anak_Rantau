# DoAR — Dompet Anak Rantau 💸
> Sistem Prediksi Risiko Defisit Keuangan Mahasiswa Rantau Berbasis Categorical Naive Bayes

Aplikasi web untuk membantu mahasiswa rantau mengelola anggaran bulanan secara bijak serta memprediksi risiko defisit keuangan menggunakan algoritma Machine Learning **Categorical Naive Bayes**.
